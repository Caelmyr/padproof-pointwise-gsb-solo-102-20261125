# PadProof

PadProof 是给锡膏印刷工位做离线复核的板面图像工作台。导入原图、画焊盘容差框、排除眩光、测量铺锡并保存带原图和分盘蒙版的复核包。

```sh
./start.sh
```

使用 Docker Compose 后打开 <http://127.0.0.1:19905/>。`PAD_PORT` 可设置本机端口，数据存在 Compose 的 `pad-data` 命名卷。运行 `./start.sh stop` 停止容器。

## 一次检测

1. 上传板面照片，或载入标明合成性质的 P-06 练习板。
2. 用 **焊盘框** 和 **排除框** 在原图拖画。右侧可编辑原图坐标或删除窗口。
3. 点击 **比例尺**，选择尺标两端，填真实毫米距离。也可以在设置中输入 px/mm。
4. 按原图灰度调整锡膏阈值，设置覆盖率的待补下限与超印上限，点击 **应用设置** 更新铺锡表。选择一个焊盘查看分盘蒙版。
5. 用 **点检** 核对一处原图像素的 RGB、灰度、检测窗口和排除标记。右侧直方图显示原图分布及过亮计数。
6. **保存复核** 后可随时展开对应记录。复核 ZIP 包包含不可变来源图、按窗口记录的 CSV、参数和数值 JSON，以及与原图同尺寸、按窗口保存的二值 PNG。修改项目后可对照旧的复核。
7. 如需处理其他曝光或作额外图像校准，可将这张原图复制到 **照片准备** 继续操作。

## 输入与算法

- 单页 PNG、JPEG、TIFF、BMP 或 WebP。最长边 4096 px，总计最多 800 万像素，上传上限 24 MiB。导入校正 EXIF 方向并建立不受后续编辑影响的 RGB8 PNG 原图。
- 每板最多 30 个焊盘窗口和 20 个排除区域。矩形以原图左上角为原点，右边和下边开区间。比例标定换算面积为平方毫米。
- 锡膏以窗口内未排除的过阈值灰度近似。覆盖率的分母是当前窗口的未排除像素数。各分盘独立检测。颗粒和内部空孔采用四邻域连通，窗口边界和排除区相接的背景不计为空孔。
- 灰度识别受照明和板面反射影响。软件提供人工复核图像与尺寸，覆盖判断取决于工位设定。
- 练习板来自确定性合成器，带焊盘、叠边、断开的锡膏岛、灯光高亮和尺标。
